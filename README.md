# The 6K Extension

Make anime study cards without needing to set up separate extensions by hand.

The installer puts everything in one place and walks you through the only
Chrome step that cannot be automated. After setup, you can:

- make Anki decks from JPDB anime episodes;
- make flash cards from ImmersionKit without an ImmersionKit account; and

## User installers: download and install

**Do not download the green “Code” button.** It is only for people who work on
the project.

Instead, open the **[latest release](../../releases/latest)** and download
exactly one installer for your computer:

| Your computer | Download | Then do this |
| --- | --- | --- |
| Windows | `The6KExtensionInstaller.exe` | Double-click it, then follow the on-screen guide. |
| Mac | `The-6K-Extension-Installer-mac.zip` | Double-click the downloaded ZIP, then double-click **The 6K Extension Installer**. |

You do **not** need Terminal, Command Prompt, programming tools, or to build
anything yourself.

The installer opens Chrome and shows you exactly what to click. Keep the guide
open while you follow it. You will be asked to turn on Chrome’s **Developer
mode**, click **Load unpacked**, and choose the folder the installer provides.
That is normal and only takes a moment.

## Before you start

- Install [Google Chrome](https://www.google.com/chrome/).
- Install [Anki](https://apps.ankiweb.net/) if you want to make Anki cards.
- Install and open [AnkiConnect](https://ankiweb.net/shared/info/2055492159)
  inside Anki if the guide tells you to.
- A free [JPDB](https://jpdb.io/) account is all you need for episode decks.

## Need help?

Open an [issue](../../issues) and include your computer type (Windows or Mac)
and an image of where you got stuck. Do not include passwords or API keys.
