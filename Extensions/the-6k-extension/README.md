# The 6K Extension

This unpacked Manifest V3 extension combines the two source extensions in this
workspace without changing either original:

- jpdb episode vocabulary → Yomitan → Anki import and review
- ImmersionKit complete sentence cards, media recovery, and Anki setup
- A unified settings page and action popup

Load `Extensions/the-6k-extension` from `chrome://extensions` with Developer
mode enabled. Select this one folder and refresh any already-open relevant
tabs. Yomitan and AnkiConnect remain separate local applications.
